# dotfiles

The archive for the dotfiles that I use daily, mostly (but not bounded to) consists the configurations of:
- [Neovim](./config/nvim)
- [Fish shell](./config/fish)
- [Wezterm](./config/wezterm)
- [Lazygit](./config/lazygit)
- [Yazi](./config/yazi)
- [Linux setup](./linux)
- [Windows setup](./windows)

## The Idea

All configs are under `config/` directory for you to explore.

On each OS directory, `linux/` and `windows/`, there is a script to create symbolic links to the configuration directories. Any modifications then will be applied automatically.
